01 — Project Overview

A prestigious college with a digital identity crisis

St. Andrew's College has held a NAAC A+ accreditation since 2023 and a legacy spanning nearly a century. Yet its website — the first point of contact for thousands of prospective students every year — fails to communicate that prestige, or serve its users effectively.

01

Core Problem

The website tries to be an archive, a noticeboard, and a brochure simultaneously — and succeeds at none of them.

With 60+ navigation links, 150+ notice entries on a single homepage, and critical information buried in un-searchable PDFs, users cannot complete basic tasks like finding fee structures, checking exam dates, or understanding how to apply. The design has no clear hierarchy, no defined user journeys, and no visual identity that reflects the college's standing.

02

Primary Users

Four distinct audiences with conflicting needs

Prospective students want course info and how to apply. Current students need timetables and exam notices. Parents seek fee structures and admission updates. Faculty need internal tools and resources. The current site treats them all identically.

03

Opportunity

A strong institution deserves a site that shows it

An A+ NAAC grade, 50+ years of operation, 3,000+ students, a 360° campus tour, and multiple best-college awards — none of this is communicated above the fold. A redesign would not just improve UX; it would actively strengthen recruitment and institutional reputation.

02 — UX Audit

What's broken, and why it matters

A systematic heuristic evaluation of the current homepage and navigation, rated by severity. Click each item to see the full detail and recommended fix.

Navigation Dual navigation bar with 60+ items Critical

The site features two separate navigation bars stacked atop each other — a utility bar with links to Administration, UNESCO, SOP, and Knimbus, and a main menu with 10 top-level dropdowns each containing 5–20 sub-items. This violates the principle of progressive disclosure and creates immediate cognitive overload for any first-time visitor.

User ImpactProspective students cannot find "how to apply" without exploring multiple dropdown paths. The information exists, but navigation friction makes it effectively invisible.
Recommended FixConsolidate to a single navbar with 5 primary items (About, Admissions, Academics, Student Life, Contact) and a global search. Move utility links to the footer.
Homepage 150+ unfiltered notices as the primary homepage content Critical

Scrolling the homepage reveals an enormous wall of PDF notices dating from 2021 to present, with no categorisation, search, or filtering. Critical 2026 admission notices are interspersed with 2022 exam timetables and 2021 grade card announcements. The list has no visual hierarchy — everything is bold text, creating sensory noise.

User ImpactStudents with urgent time-sensitive questions (exam dates, admission deadlines) cannot quickly find relevant information. The cognitive cost of scanning 150+ items causes abandonment.
Recommended FixReplace with a tabbed "Latest Updates" widget showing the 5 most recent items per category (Junior College / Degree College / General). Archive older items in a searchable notices database.
Visual Hierarchy No hero, no CTA, no value proposition above the fold Critical

The homepage opens with a plain text heading "Welcome to St. Andrew's College of Arts, Science & Commerce" on a white background, followed immediately by the notice wall. There is no imagery, no accreditation badge, no statistics, and no directional call-to-action. A prospective student arriving for the first time has no clear next step.

User ImpactBounce rate is likely high from prospective students. The A+ NAAC grade — the single most important trust signal for Indian college admissions — is invisible unless you know to look for it in a small table mid-page.
Recommended FixCreate a full-bleed hero with campus photography, the NAAC A+ badge prominently displayed, key stats, and two primary CTAs: "Apply Now" and "Explore Courses".
Accessibility user-scalable=0 disables pinch-to-zoom on mobile High

The viewport meta tag contains user-scalable=0, which prevents users from zooming on mobile devices. This is a direct violation of WCAG 2.1 Success Criterion 1.4.4 (Resize Text) and is especially harmful for users with low vision. It also signals a poor approach to responsive design.

User ImpactUsers with visual impairments cannot increase text size. The small font sizes used throughout the site (particularly in notices and dropdowns) become effectively unreadable on mobile.
Recommended FixRemove user-scalable=0 immediately. Implement proper responsive design so zoom doesn't break layouts rather than disabling zoom.
Information Access Critical information locked in unindexed PDFs High

Fee structures, academic calendars, syllabi, exam timetables, merit lists, and attendance notices are all delivered as downloadable PDFs. This means: (1) the content cannot be indexed by Google, so students searching for "St Andrews College fee structure" cannot find it via search; (2) PDFs are inaccessible to screen readers; (3) PDFs require download before reading, creating significant friction on mobile.

User ImpactThe college is invisible to search engines for its most queried content. Students from remote areas on slow connections cannot easily download large PDFs.
Recommended FixPublish key content as structured HTML pages. Academic calendars as iCal-compatible web pages. Merit lists as filterable HTML tables. Fee structures as formatted web content.
Mobile UX Desktop mega-menu fails entirely on mobile High

The multi-level dropdown navigation is designed for desktop hover interactions. On mobile touch interfaces, accessing nested dropdown items requires multiple taps with no visual affordance, and the menus frequently close before users can reach sub-items. There is no mobile-specific navigation pattern (e.g. hamburger drawer with accordion sections).

User ImpactGiven that India has >80% mobile internet usage, the majority of the college's audience is using a navigation system that functionally does not work for them.
Recommended FixImplement a full-screen mobile drawer with accordion navigation. Each primary item expands to reveal sub-items on tap, with clear back/close controls.
Search No site-wide search functionality Medium

With over 60 navigation items and hundreds of pages, the absence of a search bar forces users into a menu-exploration model. Jakob Nielsen's research shows that 50% of web users are "search dominant" — they look for a search box immediately upon arriving at a site, especially on information-heavy institutional sites.

User ImpactFinding specific information (e.g. "Psychology department faculty" or "BAMMC syllabus") requires knowing the exact menu path. First-time visitors have no mental model of the site's structure.
Recommended FixAdd a persistent search bar to the navbar. Implement keyboard shortcut (Cmd+K / Ctrl+K) for power users. Search should index all page content, not just titles.
Typography Inconsistent bold/caps usage creates visual noise Medium

The notices section uses bold formatting on nearly every line item, eliminating the typographic contrast that bold is supposed to create. Headings appear in mixed case, ALL CAPS, and title case inconsistently. There is no defined type scale — font sizes vary seemingly at random between sections.

User ImpactWhen everything is bold, nothing is. Users cannot scan for priority information. The visual noise increases cognitive load and reduces reading speed.
Recommended FixEstablish a clear type scale with defined roles. Bold only for genuine emphasis. Create a notice component with colour-coded severity levels (urgent / important / info).
Performance WordPress plugin bloat slows page load Medium

The site loads the ResponsiveVoice text-to-speech library on every page, alongside multiple WordPress plugins. There is no evidence of image optimisation, lazy loading, or a CDN. The homepage notice section renders hundreds of DOM elements simultaneously.

User ImpactPage load time directly correlates with bounce rate. A 1-second delay in mobile load time reduces conversions by up to 20% (Google, 2018). Students on slower connections in outer Mumbai areas may abandon before the page loads.
Recommended FixConduct a plugin audit. Implement lazy loading for images. Paginate or virtually scroll the notices list. Consider a static site generator for public-facing pages.

04 — Recommendations

Five strategic changes, in priority order

Each recommendation addresses a specific failure mode identified in the audit, with clear rationale and expected outcome.

1
Fix accessibility violations immediately
P0 · Urgent

Remove user-scalable=0 from the viewport meta tag. Add skip navigation links. Announce PDF links with an icon. Ensure all interactive elements have visible focus states. These changes have zero design cost and eliminate legal and ethical liability. WCAG 2.1 compliance is mandatory for Indian government-affiliated institutions under the Rights of Persons with Disabilities Act, 2016.

AccessibilityZero CostWCAG 2.1
2
Consolidate navigation to 5 primary items with search
P1 · High

Replace the dual navbar with a single bar containing About, Admissions, Academics, Student Life, and Contact. Each opens a two-panel fly-out on desktop and an accordion in a mobile drawer. Add a global search with Cmd+K keyboard shortcut. This single change reduces the navigation decision space from 60+ options to 5, dramatically reducing cognitive load for new visitors.

NavigationIASearchMobile
3
Redesign homepage around clear user journeys
P1 · High

Add a "I am a…" selector (Prospective Student / Current Student / Parent / Alumni) above the hero that filters homepage content. Replace the 150+ notice wall with a tabbed updates widget showing 5 most-recent items. Create a 6-icon quick-action bar for the most-visited tasks. Display the NAAC A+ badge and key stats prominently above the fold. Add a real hero image of the campus.

HomepageContent StrategyUser Journeys
4
Convert critical PDFs to web-native content
P2 · Medium

Publish academic calendars as filterable web pages with iCal export. Convert merit lists to searchable HTML tables with roll number filtering. Create structured department pages for each course with syllabus content in HTML. This improves SEO substantially — students searching "St Andrews BSc IT syllabus" or "FYJC merit list 2026" should land directly on the relevant page, not navigate through menus.

SEOContentAccessibilityMobile
5
Establish and roll out a visual design system
P2 · Medium

Define a token-based design system: two typefaces (a serif for headings, a clean sans for body), a 6-colour palette, spacing scale, component library of cards, badges, and notice types. Standardise the notice/alert component with colour-coded severity. Apply consistently across all 100+ pages. This work amortises across every future update — consistent design reduces maintenance cost and strengthens the institutional brand.
